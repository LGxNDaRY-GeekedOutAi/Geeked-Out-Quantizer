## [Unreleased]

### Added
- Initial release of Geeked.Out Quantizer
- GGUF model quantization with llama.cpp integration
- Importance-aware IQ2_M quantization support
- Automatic imatrix generation
- Hardware detection (CPU, GPU, RAM)
- PowerShell quantization pipeline
- Electron desktop application
- Multiple quantization presets (Fast, Balanced, Quality, Extreme)
- CUDA GPU acceleration support
- Dark/Light/High Contrast/Colorblind themes
- Batch quantization support
- Progress tracking with ETA
- Configuration management
- Preset save/load functionality
